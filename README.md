# GreenApi

# Telegram Chat

## Возможности

* авторизация Telegram-аккаунта через `idInstance` и `apiTokenInstance`;
* подтверждение аккаунта по номеру телефона и коду;
* поддержка 2FA-пароля;
* выбор получателя по номеру телефона;
* отправка текстовых сообщений;
* получение входящих сообщений;
* отображение переписки в интерфейсе.

## Стек

* React
* TypeScript
* Vite
* Axios
* React Router
* Zustand
* Tailwind CSS

## Установка

```bash
npm install
```

## Переменные окружения

Создайте файл `.env` в корне проекта:

```env
VITE_GREEN_API_URL=https://4100.api.green-api.com
```

## Запуск

Для запуска development-сервера:

```bash
npm run dev
```

После запуска приложение будет доступно по адресу, который выведет Vite.

## Как работает авторизация

1. Пользователь вводит `idInstance` и `apiTokenInstance`.
2. Приложение проверяет состояние GREEN-API instance.
3. Если instance уже авторизован — пользователь сразу попадает в чат.
4. Если требуется авторизация, пользователь вводит номер телефона.
5. После получения кода вводит код подтверждения.
6. При необходимости вводит пароль двухфакторной аутентификации.
7. После успешной авторизации открывается страница чата.
